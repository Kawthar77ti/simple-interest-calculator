
# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (P * R * T) / 100

Where:
- P = Principal amount
- R = Annual interest rate
- T = Time in years

## Features
- Easy to use
- Calculates simple interest
- Uses a simple mathematical formula

## Example
Principal = 1000
Rate = 5%
Time = 2 years

Simple Interest = (1000 * 5 * 2) / 100 = 100

Total Amount = 1100
